╔══════════════════════════════════════════════════════════════╗
║                                                              ║
║   SE DER ERRO NO PUSH                                       ║
║                                                              ║
╚══════════════════════════════════════════════════════════════╝

Possíveis causas:

1. SEM INTERNET:
   - Verifique sua conexão
   - Tente novamente: git push

2. CREDENCIAIS INVÁLIDAS:
   - Use Personal Access Token (PAT)
   - Não use senha antiga do GitHub
   - Gere novo token em: github.com/settings/tokens

3. BRANCH DESATUALIZADO:
   - Baixe mudanças primeiro: git pull
   - Resolva conflitos (se houver)
   - Tente push novamente: git push

4. REMOTE NÃO CONFIGURADO:
   - Verifique: git remote -v
   - Configure: git remote add origin <url>
