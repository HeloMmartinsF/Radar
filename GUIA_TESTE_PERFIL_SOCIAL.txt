═══════════════════════════════════════════════════════════════
 PROBLEMAS COMUNS E SOLUÇÕES
═══════════════════════════════════════════════════════════════

❌ ERRO: Página não carrega (404)
✓ SOLUÇÃO: Execute COPIAR_PERFIL_PARA_TARGET.bat novamente

❌ ERRO: "Usuário não autenticado"
✓ SOLUÇÃO: Faça login em /login.html primeiro

❌ ERRO: Produtos não aparecem
✓ SOLUÇÃO: 
   1. Verifique se o usuário logado é fornecedor
   2. Verifique se há produtos cadastrados para este fornecedor
   3. Abra /api/perfil/meu e veja se "produtos" está vazio

❌ ERRO: Compilação falha
✓ SOLUÇÃO: 
   1. Verifique se Java 17 está instalado (java -version)
   2. Execute: .\mvnw.cmd clean compile -X (modo debug)

❌ ERRO: Foto não faz upload
✓ SOLUÇÃO:
   1. Verifique se a pasta existe: src/main/resources/static/uploads/perfis
   2. Verifique permissões de escrita

❌ ERRO: Modal não abre
✓ SOLUÇÃO:
   1. Abra console do navegador (F12)
   2. Veja se há erros JavaScript
   3. Recarregue com Ctrl+Shift+R (hard refresh)
